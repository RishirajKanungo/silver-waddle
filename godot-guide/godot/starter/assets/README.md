# Shardbound assets

Original pixel art and sound for the Shardbound starter project, generated by `npm run assets` from
`src/art/data/*.ts` in the guide. Released as CC0 (see `LICENSE.txt`).

## Importing

- The project already sets **Rendering > Textures > Canvas Textures > Default Texture Filter** to *Nearest*, so pixels stay crisp.
- Sprite sheets are grids. In a `SpriteFrames` resource use *Add frames from sprite sheet* and enter the grid size from the table (horizontal × vertical).
- Frame indices are row-major: `index = row * columns + column`. Side-facing animations face **right**; set `flip_h` for left.
- Characters have their pivot at the feet (`origin`). Set the `AnimatedSprite2D` offset to `-origin` (or `centered = false` and `offset = -origin`).
- Tilesets are 16×16 tiles, 16 per row. Create a `TileSet` with tile size 16×16 and add the PNG as an atlas source.
